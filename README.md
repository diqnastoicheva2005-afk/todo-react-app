### 2. 💻 Local Setup (Standard Installation)

If you prefer to run the app locally on your machine, follow these steps:

#### 📌 Prerequisites:

* Node.js (v18 or higher)
* npm (v9 or higher)

#### 🛠️ Steps:

1. Clone the repository:

```
git clone https://github.com/diqnastoicheva2005-afk/todo-react-app.git
```

2. Install dependencies:

```
npm install
```

3. Start the application:

```
npm run dev
```

4. Open in browser:
   Go to the URL shown in your terminal (usually http://localhost:5173).
